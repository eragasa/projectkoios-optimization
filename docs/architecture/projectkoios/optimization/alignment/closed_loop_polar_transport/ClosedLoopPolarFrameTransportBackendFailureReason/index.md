# ClosedLoopPolarFrameTransportBackendFailureReason

`ClosedLoopPolarFrameTransportBackendFailureReason` provides bounded backend-failure
classification:

- `NONCONVERGENCE`;
- `NONFINITE_OUTPUT`; and
- `INVALID_DECOMPOSITION`.

Consumers can map unresolved computation without parsing exception text. These reasons
do not represent mathematical rank deficiency, which remains ordinary result evidence.
