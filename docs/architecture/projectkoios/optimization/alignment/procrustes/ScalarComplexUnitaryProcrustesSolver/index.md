# ScalarComplexUnitaryProcrustesSolver

`ScalarComplexUnitaryProcrustesSolver` specializes the generic solver base to one
dependency-free matrix pair and one scalar result. Its final solve template owns
orientation, backend-output validation, rank evidence, transformation withholding,
residual evidence, and result construction.
