\chapter{SciPy batched Procrustes status}

No SciPy batched Procrustes definition, solver, result, or façade is currently
implemented or exported. Installing the \path{scipy} optional dependency does not add a
batched Procrustes API.

For dense exact complex128 batches, use the NumPy procedure in the preceding chapter:
\begin{lstlisting}[language=Python]
from projectkoios.optimization.alignment.numpy.batched_procrustes import (
    NumpyBatchedComplexUnitaryProcrustesDefinition,
    NumpyBatchedComplexUnitaryProcrustesSolver,
)
\end{lstlisting}
Do not infer SciPy Procrustes availability from unrelated SciPy capabilities in the
distribution, and do not import an internal or guessed SciPy alignment path.

A future SciPy backend would require a distinct representation or execution need, an
explicit public contract, independent numerical qualification, and isolated-wheel
verification. It will not be introduced as a name-only wrapper around NumPy.
